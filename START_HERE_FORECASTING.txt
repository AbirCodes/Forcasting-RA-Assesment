🎯 WHAT THIS DOES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ✓ Sets up Python environment
  ✓ Installs all dependencies (pandas, numpy, sklearn, torch, tensorflow, etc.)
  ✓ Detects and configures GPU support
  ✓ Cleans and preprocesses PGCB hourly generation data
  ✓ Engineers features (lags, rolling stats, time features, cyclical encoding)
  ✓ Trains 5 state-of-the-art models:
    • LightGBM (Gradient Boosted Trees)
    • N-BEATS (Neural Basis Expansion Analysis)
    • TCN (Temporal Convolutional Network)
    • TFT (Temporal Fusion Transformer)
    • Informer (Efficient Transformer)
  ✓ Evaluates with MAE, RMSE, MAPE metrics
  ✓ Generates visualizations and diagnostic plots

Forecast Horizons: 1h, 6h, 24h ahead

💡 HOW IT WORKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Phase 0: Environment Setup
  ├─ Check/install dependencies
  ├─ Detect GPU (CUDA)
  └─ Configure for optimal performance

Phase 1: Data Loading
  ├─ Load PGCB dataset (92,650 hourly records)
  └─ Identify target variable (generation_mw)

Phase 2: Data Cleaning
  ├─ Remove duplicate rows
  ├─ Convert timestamps to datetime index
  ├─ Impute missing values (linear interpolation)
  └─ Handle outliers (cap at domain knowledge + IQR)

Phase 3: Feature Engineering
  ├─ Time features (hour, day, month, weekend)
  ├─ Cyclical encoding (sin/cos for hour, day, month)
  ├─ Lag features [1, 2, 3, 6, 12, 24, 48, 72, 168 hours]
  ├─ Rolling statistics (mean, std, min, max)
  ├─ Exponential moving averages (EMA)
  └─ Difference features (for stationarity)

Phase 4: Data Splitting
  ├─ Chronological split (80% train / 20% test)
  ├─ NO SHUFFLING (preserve temporal order)
  └─ Feature scaling (StandardScaler)

Phase 5: Model Training
  ├─ LightGBM (fast, accurate, interpretable)
  ├─ N-BEATS (state-of-the-art for univariate)
  ├─ TCN (excellent for sequence modeling)
  ├─ TFT (attention-based, interpretable)
  └─ Informer (efficient long-series)

Phase 6: Evaluation
  ├─ Metrics: MAE, RMSE, MAPE
  ├─ Forecast plots vs actual
  ├─ Residual analysis
  └─ Feature importance

GPU speeds up deep learning models by 5-10x.

To enable GPU:
  1. Install CUDA Toolkit: https://developer.nvidia.com/cuda-downloads
  2. Install cuDNN: https://developer.nvidia.com/cudnn

PyTorch with GPU:
  pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118

TensorFlow with GPU:
  pip install tensorflow[and-cuda]

Verify GPU:
  python -c "import torch; print(torch.cuda.is_available())"
